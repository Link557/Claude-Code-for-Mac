# 下一条输入建议（Windows win.7）

使用 SDK `promptSuggestions: true`，持续读取 `result` 后的 `prompt_suggestion`。建议作为独立、带版本的会话事件和临时快照字段传递，不写入用户消息或历史正文。新输入、切换模型/模式、中断、关闭会话会清除建议；仅接受成功轮次结束后、当前会话空闲时的建议。

输入框为空、无附件、无排队编辑/弹层且可以输入时，显示灰色建议与“Tab 接受”。Tab 只将建议填入草稿，Enter 才发送。输入内容或 Escape 会隐藏本条建议，清空草稿不会立即恢复它；中文输入法选词和 Shift+Tab 不接受建议。建议不保证每轮出现，CLI 的配置开关与生成条件仍然生效。

验证：

- 34 项相关测试通过，涵盖 result 后的事件、过期/错误/跨会话建议、快照竞态、Tab/Enter、输入法、草稿保留及输入历史回归；类型检查和构建通过。
- 官方原生 CLI 实测收到“写测试”“写边界测试”等真实建议。
- 打包后的 exe 通过真实会话验证灰色提示、Tab 填入但不发送、Enter 发送，并在下一轮显示新的建议。
- 第三方协议验证：真实 CLI 连接本地 Anthropic-compatible 测试端点，使用 `deepseek-chat` 模型 ID，收到 `prompt_suggestion`。这证明该接口链路支持第三方配置，不代表已验证真实 DeepSeek 服务、供应商权限或所有网关。当前机器没有已配置的真实第三方端点。

提示生成是一次额外模型请求，会产生相应用量。官方说明：https://code.claude.com/docs/en/interactive-mode#prompt-suggestions
