# Mac 通用功能同步与优化记录

核对日期：2026-11-08。目标是当前本地 Mac 项目，不整分支合并，不改变 Mac 图标、交通灯、⌘ 快捷键、终端与签名策略。

## 依据与决策

- 云端总清单：[Issue #10](https://github.com/Link557/Claude-Code-for-iOS/issues/10)。
- Windows 参考基线：`f977a8bc772d279861af0d39cbff1c6fe1f73304`。
- 本地基线：`7ab9a88`，另有此前完成但未提交的额度补试、模型目录、插件技能读取和图片预览改动。本次保留这些改动。
- 用户确认 Fable 按 CLI 目录显示，不采用云端新增的“始终补一个 Fable 入口”。映射修正只作用于已经存在的 CLI 行。
- 登录状态、配置解析、模型调用成功是不同证据。界面不把前两项宣传为供应商权限或实际后端鉴定。

## 验证方式

1. 先运行类型检查与全量 Vitest，覆盖 IPC、设置、会话回收与接续、路由隔离、模型映射、通知来源和输入建议竞态。
2. 构建后运行 `scripts/smoke-mac-sync.cjs`。它使用隔离配置和真实 Mac CLI 做接入、项目路由与设置读取；用合成会话事件验证通知、建议按键和摘要动效，不发送付费模型请求。
3. 前轮的 `scripts/smoke-model-skills.cjs`、`scripts/smoke-tool-images.cjs` 保留为对应功能的原生 UI 验证入口。
4. 截图输出到 `dist/build-check`；测试不修改用户现有认证或供应商设置。

本轮结果：104 个测试文件、663 项测试全部通过；类型检查、生产构建和改动格式检查通过。原生 Mac 冒烟检查通过，实际读取 CLI 2.1.301，确认 gateway 路由、无官方额度、本机偏好落盘，以及合成建议只在 Enter 后发送。已检查浅色和深色界面截图。

## 验证边界与后续验收

- 2.1.299 的 Mac 二进制获取失败；没有依据添加该版本的默认值表。未知版本和未经审核的字段继续显示未知。可取得二进制后对照原生设置逐项审核。
- 本机未安装 Matt 技能包，技能逻辑使用多层目录 fixture 验证，不能把 fixture 数量宣传为用户安装包数量。
- 输入建议用合成 SDK 事件完成界面与状态验证；没有额外付费请求，不宣称验证过真实 DeepSeek 服务或每个模型的建议生成。
- 终端接续的后端状态与历史刷新有回归测试；真实付费会话跨进程往返、执行中接管和跨进程写入锁不在本轮已验证范围。
- 保留原有 POSIX/中文/空格路径与文件预览测试，不为同步功能引入 Windows 盘符或 PowerShell 行为。
- 本地改动没有自动提交、推送、关闭云端 Issue 或替换已安装应用。打包签名和安装版升级仍需单独验收。
