# Windows 桌面端待办

记录于 2026 年 11 月 10 日。当前桌面端已跟随本机 Claude Code CLI。以下是使用中发现的问题、待讨论的安装方案和待审查的架构问题。

## 会话标题栏的 CLI 接续入口

Windows 桌面端仍显示终端图标，现有入口「在 CLI 继续」会复制 PowerShell 接续命令。待处理范围包括图标和命令入口。验收时分别检查标题栏入口已移除，以及在 CLI 里完成一轮后，回到桌面仍能自动读到同一会话的新消息。

## Fable 用量显示为零

用户反馈当天持续使用 Fable。截图中，从「剩余额度」进入使用情况页并选中 2026 年 11 月 10 日的 Fable 后，累计、输入、输出、缓存读取和缓存写入 Token 均为 0，缓存命中率显示为横线。

后续用当天已有的 Fable 会话核对实际模型 ID、Token 记录、日期归属和 Fable 分类，再检查图表刷新。截图对应的是本机按模型统计的 Token 明细，订阅的 5 小时和每周剩余额度需分别核对。验收时，同一条有用量记录的 Fable 回复应计入当天的 Fable 和 Total，输入、输出及缓存字段与记录一致。

## 新会话自动标题

用户记得此前会自动生成标题。当前截图中，侧栏显示以 `@C:/Users/20…` 开头的标题，像是取了首条输入的片段。自动标题流程是否仍在，以及截图中的标题是否只是临时标题，有待核实。

后续分别用普通首条消息和以文件引用开头的消息复现，检查首轮结束后标题是否更新，以及重新打开应用后是否保留。核对手动改名是否会被迟到的自动标题覆盖。

## 右侧栏顶部三个按钮的排版

右侧栏顶部的「新建页面」「展开或还原宽度」「展开或收起右栏」三个按钮排在一起时，间距、对齐和视觉重量不协调。后续把这三个按钮作为一组调整，验收时对照右栏普通宽度、展开和收起状态，检查按钮对齐、间距及悬停和选中样式。

## 缺少本机 CLI 时的一键安装方案

欢迎页的模型选择步骤、新对话页和「设置 → 账号与接入」复用一张「未检测到 Claude Code CLI」卡片。主按钮为「一键安装」，同时提供「选择已有 CLI」和「稍后」。

1. 点击安装后先重新检测。确认缺失时，使用 Anthropic 官方 Windows 原生安装方式安装到当前用户环境，卡片按实际进度显示安装和验证状态。 [Anthropic Windows 安装文档](https://code.claude.com/docs/en/setup#install-on-native-windows)
2. 安装完成后重新检测本机 `claude.exe`，运行 `claude --version` 验证，再刷新模型列表。终端和桌面继续使用同一份本机 CLI。
3. 已有认证时返回原页面。尚未登录时提供独立的「登录 Claude」入口，复用现有官方登录流程。安装失败时显示具体原因，并提供重试和官方安装说明。

手动路径失效时提供重新检测和重新选择。CLI 可以运行但模型读取失败时，提供重试读取。

## 模块职责与依赖审查

待审查桌面端是否做到高内聚、低耦合。优先核对 CLI 检测、安装与接入，模型目录与会话实际模型，会话历史与用量统计这几处边界。检查同一业务规则是否分散在多个模块、同一状态是否由多处维护，以及界面是否依赖主进程或 SDK 的实现细节。

审查时记录具体模块、依赖方向和改动牵连的范围，再决定哪些边界值得调整。

## 技能正文在对话中自动展开

调用技能后，CLI 的成功回执和技能正文是不同消息。实时技能正文标记为合成消息，桌面端将其作为普通通知展开。历史读取则会过滤该正文。

后续仅在同一工具范围内能唯一匹配成功的 Skill 回执时收起正文，保留技能卡、错误提示和用户手动粘贴的内容。技能正文继续进入模型上下文，原始会话记录保持完整。

## 已确认的实施与验收方案

- CLI 接续入口整体移除，保留现有历史同步和执行中会话保护。使用真实 CLI 接续同一会话，验证桌面回焦和后续发送的历史连续性。
- Fable 用量来源是本机历史中的模型和 Token。打开页面主动扫描，首次读取显示占位，刷新或失败时保留上次成功结果。并发刷新合并，并验证外部追加、真实零用量和失败状态。套餐额度单独展示。
- 标题依次采用手动标题、CLI 标题、本地备用标题。备用标题优先使用文件引用后的任务文字，仅有附件时使用文件名。首轮完成后刷新并在必要时补查，防止旧请求覆盖手动改名。
- 右栏三个按钮统一为 32 × 32 点击区域、4 px 间距。验证普通、展开、收起状态和 Windows 快捷键提示。
- 技能正文仅在成功回执、合成标记和同一工具范围唯一匹配时收起。用真实 CLI 与本地模拟服务验证实时消息和重开历史一致，并保留错误与用户粘贴内容。
- 欢迎页、新对话和账号设置复用 CLI 安装卡片。区分缺失、手动路径失效、不可运行和可用，缺失时按官方 Windows 发布清单校验 SHA-256 和签名后执行原生安装。安装进度、失败原因和重试状态可见，成功后重新检测版本并刷新模型和命令。
- 接入模块统一 CLI 文件标识，模型与命令缓存共用并在安装、路径变化和回焦检测到替换时刷新。保留运行中会话的当前进程。

交付前执行类型检查、全量测试和 Windows 打包，检查包内无 claude.exe，并用本机 CLI 验证候选包。覆盖隔离安装流程，真实首次安装需在干净 Windows 环境验收，环境不可用时记录待验收。候选包通过后更新桌面及开始菜单快捷方式，保留现有包作为回退。
