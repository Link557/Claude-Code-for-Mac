# 子 Agent 摘要与会话侧栏

## 已确认设计

- 保留现有窗口、主对话、输入框及橙色主 Agent；主 Agent 不进入子 Agent 计数。
- 新子 Agent 开始时，自动打开右上角摘要并展开子 Agent 分类。同一调用只自动展开一次，不抢输入焦点。
- 总数统计实际子 Agent，进行中数只统计 `running`；完成的 Agent 保留在列表中。
- 子 Agent 采用现有像素小螃蟹，颜色避开橙色和紫色，按首次出现顺序固定身份；配饰依次为眼镜、帽子、莫西干发型。
- 摘要展开时，工作中的螃蟹轻微踏步、抬手、眨眼。完成、失败、停止、未知状态保持静止，遵守减少动态效果设置。
- 点击螃蟹或任务行，在现有右侧栏的同一个“子 Agent”页查看和切换真实子会话，收起摘要，保留主对话位置。

## 数据与实现

1. 沿用会话摘要中的 Agent 工具调用记录，不把主循环、Shell 或监控任务计入子 Agent。
2. 保留 SDK 返回的子 Agent ID，用已有工具调用 ID 关联主对话的任务参数、实时子消息和最终结果。
3. 历史详情通过 SDK `getSubagentMessages` 读取当前主会话所属子记录；只接受该主会话已确认的工具调用，不接受界面任意指定文件路径或子 Agent ID。
4. 复用现有 Markdown、工具调用卡片与小螃蟹组件。运行中的详情页按需刷新，隐藏或切换后停止刷新，异步返回不能串到其他 Agent。
5. 没有内部记录时显示实际可用的任务和结果，并明确说明内部会话不可用；读取错误可见且可重试，不伪造消息。
6. `main-session`、ambient 和 skip-transcript 活动不作为子 Agent 展示；无工具关联的任务保留在跟踪器并提示数量可能不完整。后续关联使用同一任务别名去重通知，不按描述猜测身份。
7. 仅信任唯一工具结果的 SDK 顶层身份；历史文本只解析确认的尾注格式，且需要子记录的父工具归属佐证。SDK 可能将读取失败返回为空记录，界面不能将其误报为确定不存在。

## 验收

- 三个真实 Agent 调用得到总数 3、进行中 3；一项完成后总数仍为 3、进行中变为 2。
- 重复事件不重复计数或反复打开；新增调用会重新打开并展开分类；会话状态相互隔离。
- 身份颜色、配饰在摘要、完整列表和详情中一致，完成后不变。
- 点击打开、切换、重复点击复用标签；标签已满时显示提示。
- 实时和历史消息按所属 Agent 隔离，主消息与其他 Agent 消息不混入。
- 单元与界面回归、类型检查、构建，以及真实渲染器中的合成事件冒烟验证；不为验证向模型发送额外任务。
